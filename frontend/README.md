# Ethico frontend

A Flutter EAN camera scanner, manual input, and product lookup screen.

See the [repository README](../README.md) for setup, run, and test commands.

Source-attributed product details and browser links are implemented in
`lib/product_details.dart`; `lib/product_api.dart` handles HTTP and response parsing.
Tests are in `test/widget_test.dart` and `test/product_details_test.dart`.
See [project status](../docs/status.md) for test evidence and platform limitations.
